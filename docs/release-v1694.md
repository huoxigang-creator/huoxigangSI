# V-1-6-94 截图直接追加识别

新增“截图快捷识别”入口，可先打开智能识别弹窗再截图，无需先选择文件。

弹窗打开时支持Ctrl+V直接粘贴截图，图片追加至已有图片末尾并自动识别；保留原房间、柜体、图形和手动修改。当前识别或PDF导出未完成时，截图进入等待队列（最多等待20张），按顺序处理，不中断现有识别。每张截图沿用10MB上限，失败时保留可手动填写行。

“开启截图自动接收”在用户点击后请求浏览器剪贴板读取权限；已有读取权限时打开弹窗自动启用。仅在HTTPS/localhost且页面可见、窗口有焦点时检测；截图后返回此窗口会自动追加。开启时读取的旧图片作为基线不上传，后续相同剪贴板图片不会重复处理；截图和粘贴共用图像内容指纹，避免同图重复请求。

关闭弹窗、停止识别或暂停自动接收时，移除相关监听并停止检测；关闭时清空待处理截图，异步读取晚返回也不再导入。只提取PNG/JPEG/WebP图片，不读取剪贴板文字或HTML内容。未授权或浏览器不支持自动读取时，提示使用Ctrl+V，不反复弹出读取申请。

验证：36项剪贴板、真实组件事件、识别计量、CAD和PDF相关自动测试通过；TypeScript检查及生产构建通过。组件测试使用内存模拟识别响应，覆盖首次粘贴、识别期间排队、重复图像、自动接收基线、失焦及关闭；未改动真实业务记录。浏览器预览被用户权限门拒绝，未绕过，也未声称已完成真实浏览器验收。浏览器原生截图/剪贴板行为仍取决于所用浏览器权限与窗口焦点。
