# V-1-7-12 厨房平面图标题作为柜名

厨房项目图框允许左下角“地柜平面图”“吊柜平面图”“台面平面图”作为柜名依据，分别归为地柜、吊柜、台面。用户DWG中台面实际标题为“石英石平面图”，一并将该标题及“石英石台面平面图”归为台面。这是厨房视图标题的明确例外，颜色不限；普通图框仍按原红色柜名规则，项目名称仍作为房间来源，冰箱柜保持面积规则。CAD和截图提示词同步更新，不将地柜、吊柜和台面的尺寸混成一条。

实际使用用户厨房.dwg（约1MB）通过现有受限转换工具得到DXF，仅作解析验证，未写业务数据库；结果：厨房地柜1995+2225=4220mm，厨房吊柜2161mm，厨房台面1995+2225=4220mm，均为空高度/延米计价。缺台面标题时曾将该图尺寸错误归入最近地柜；识别出石英石平面图作为独立锚点后尺寸各自正确配对。用户原图、转换文件及检查脚本位于忽略输出目录，不提交GitHub，服务器临时测试文件清除。

验证：CAD与截图提示词34项测试、首页构建依赖检查通过；TypeScript及生产构建通过。合成测试覆盖四种标题、白色标题、分图尺寸和延米；真实DWG验证地柜4.220m、吊柜2.161m、台面4.220m。截图使用模拟接口测试提示词，未调用付费模型测真实图片准确率。
