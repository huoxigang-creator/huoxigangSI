# V-1-6-96 DWG转换工具接入

安装GNU LibreDWG 0.14命令行工具，前端直接上传DWG后由服务器转换为ASCII DXF，再复用柜体名称、尺寸、计价和图形预览解析，不调用豆包AI。

源码来自GNU发布版的清华镜像，SHA256固定为62ebb73b984f865960f20ed26619ea5f8789d5e3fd088fa40a2598384da81275。使用GNU官网下载的发布签名验证通过，签名公钥指纹38A4167B0DB69E49C5F7216CB8C28866AB27A7A2。服务器保留源包及COPYING。安装脚本见deploy/install-libredwg-0.14.sh，采用单线程、低内存编译选项。

运行工具位于/opt/gugemei/tools/libredwg-0.14/bin/，网站调用/opt/gugemei/tools/dwg2dxf-limited，由gugemei.service.d/dwg-converter.conf配置。工具按需启动，退出释放内存；仅固美格服务新增该配置，访问范围保持不变。

转换仍一次一个任务，限制640MiB虚拟地址空间、100MiB输出文件、100秒CPU时间和110秒墙钟时间。API修正显式-o输出参数，区分未安装、超时/资源限制和转换失败；转换结果读取前验证大小并清理临时目录。复杂或不兼容图纸仍需在原CAD中另存DXF，不能保证所有版本及全部三维实体均完整保留。

恢复部署顺序：先上传并运行install-libredwg-0.14.sh，再运行对应install-v1696.sh。安装工具阶段不重启网站，应用发布阶段备份现有数据库并保留旧应用。

自动验证：31项CAD转换接口、尺寸解析、预览及上传客户端测试通过，TypeScript检查与生产构建通过。测试包括转换参数、输出上限、超时/内存错误和临时文件清理；不创建或更改真实业务记录。
