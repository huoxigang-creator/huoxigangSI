# 客户报价分享与收款码图片

版本：2026-10-13 V-1-3-10。

在客户或项目的报价页点击「分享给客户」，上传自己的收款码图片，或选择以前上传的图片，再填写有效期、客户说明，以及可选的收款项名称和本次金额。创建客户链接后，可以复制链接发到微信，也可以下载 PDF 后发送。上传图片可重复用于多份报价，每份分享固定使用所选图片；以后上传新图不会替换旧分享里的图片。

当前默认使用收款码图片，不需要配置微信支付接口。PNG/JPEG 原图保存在 R2，图片元数据保存在现有 D1 记录中。限 5 MB，任一边不超过 4096 像素、总像素不超过 1000 万；服务端校验图片格式和尺寸。图片只可由所有者上传和选择，客户仅能通过有效的专属报价链接读取对应图片。报价链接到期或停用会停止在线访问；已经下载或转发的 PDF 和图片仍由接收人持有。

客户页面和 PDF 包含销售明细、金额、结算、主动填写的客户说明，以及所选收款码图片。它们不包含成本、利润或内部备注。PDF 中的「查看报价二维码」打开客户页面，另一个「收款码」是上传的收款图片，二者分别标注。每次分享保存报价快照；编辑原报价不会改变已经分享的价格。分享操作本身不会登记收款，也不会采纳报价。

静态图片不能反馈到账金额或支付状态。客户付款后，由商家核对实际到账，再在原项目登记收款并填写对应报价和收款项说明。定金、进度款、尾款可以分别生成分享。报价来源与收款项和实际收款金额的核对需要商家完成。

## 当前启用状态

站点入口已按所有者授权设为公开，客户专属报价链接已启用免登录访问。管理页面、管理 API、收款码上传和 MCP 业务操作仍验证原所有者身份。客户链接是访问凭证，知道链接的人能看到这一份销售报价及附上的收款码，可设置到期或停用。

微信商户自动收款仍未开通：未提供商户运行时参数，也未进行真实下单或付款验证。图片模式不创建微信支付订单、不请求客户微信身份、不查询付款状态、不自动登记流水。软件只展示所上传的图片，不验证该图片能否付款；使用前应由商家核对图片及其收款人。以下接口配置说明保留供未来另行开通时使用。

## 运行时设置

只通过 Sites 生产运行时设置保存配置；秘密必须标为 secret，不写入源码、PDF、客户网页或本文件。

| 名称 | 用途 | secret |
| --- | --- | --- |
| SITE_ORIGIN | `https://gugemei-project-manager.huo-xigang.chatgpt.site` | 否 |
| QUOTE_CUSTOMER_ACCESS_ENABLED | 客户访问授权并开启后设为 `true` | 否 |
| WECHAT_PAY_MCHID | 微信支付商户号 | 否 |
| WECHAT_PAY_APPID | 已绑定该商户的公众号 AppID | 否 |
| WECHAT_PAY_MERCHANT_SERIAL | 商户 API 证书序列号 | 否 |
| WECHAT_PAY_PRIVATE_KEY | 对应商户私钥，PKCS8 PEM 格式 | 是 |
| WECHAT_PAY_API_V3_KEY | 32 字节 APIv3 密钥 | 是 |
| WECHAT_PAY_PUBLIC_KEY_ID | 微信支付公钥 ID | 否 |
| WECHAT_PAY_PUBLIC_KEY | 对应微信支付公钥，PEM 格式 | 否 |
| WECHAT_APP_SECRET | 公众号网页授权所用 AppSecret | 是 |

商户后台需开通对应 Native/JSAPI 产品，并配置公众号网页授权域名、JSAPI 支付授权目录及商户绑定关系。配置前核对现有商户和公众号的实际权限。通知地址由服务端设为 `SITE_ORIGIN/api/wechat-pay/notify`；OAuth 回调为 `SITE_ORIGIN/api/wechat-pay/oauth`。运行时设置修改后，部署已保存版本使设置生效。

## 微信商户接口入账规则（尚未启用）

服务端核验微信响应和通知的签名，解密通知，检查商户号、AppID、订单号、币种和金额。只有微信确认 SUCCESS 才登记收款。重复或并发通知只插入一笔流水与一条审计；主动查单可补记遗漏通知。所有写入使用同一 D1 原子事务。

收款金额记录经微信核验的订单总额，另外保留微信返回的实际付款金额字段，以区分优惠券等情况。此处登记微信交易成功，不表示银行结算已经完成。退款、手续费和银行结算对账不包含在本次功能中。

同报价的已收款和待付款订单共同限制在该报价应收内，其他报价不占用它的收款额度。无法确认是否扣款的失败尝试保留原订单号，防止重复下单。一个分享只关联一个付款订单，发起后保持原支付方式；已关闭或订单到期时重新分享。分享关闭或到期以后收到的真实成功通知仍登记，避免漏记已付资金。

## 开通验证

客户免登录访问授权后，再启用对应运行时开关。配置商户参数并部署后，先检查商户与公众号绑定、客户微信授权回跳、实际下单、签名回调和总账关联。真实付款需由授权付款人操作，核对微信交易号、报价来源、收款项、金额，以及重复查单不会再次入账。完成这些检查前，不应把功能称为已经开通的自动收款。
