# V-1-6-93 图纸预览、客户核对 PDF 与完整信息去重

- CAD解析结果按柜体显示原文件二维线条与尺寸标注，支持线段、多段线（含常见旧式二维多段线）、圆弧、圆及插入图块变换。标注依原尺寸位置重绘；预览不包含填充、外部参照和三维实体，缺少二维图形时明确提示补充截图，不根据计价尺寸虚构柜体外形。
- 预览支持100%至400%放大。图形与对应识别行同步保留、追加、过滤和删除。
- 底部新增“一键导出图纸核对PDF”，导出当前勾选项；截图与CAD均支持。一柜一页A4，包含名称、房间、当前手动修改后的宽高和㎡/延米、识别参考、图形、数量合计、客户核对签字及日期。当前核对值与原图标注分别说明，不输出单价、成本和利润。

- 混合上传后重新识别截图时保留既有CAD项；手动编辑过程不自动移除正在填写的行。

- 安全答案输入与确认默认明文可见，可随时切换显示/隐藏；设置与短信登录/找回页面统一支持中文提示，仍按原有长度验证、加盐摘要和双重验证机制处理。未读取或修改真实账号答案。
