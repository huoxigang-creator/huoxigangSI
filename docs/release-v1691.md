# V-1-6-91 CAD上传扩容

用户要求：每个CAD文件最大100MB，每次最多30个文件。保留既有计价规则和报价草稿核对流程。

实现：前端统一验证1至30个文件、单个不超过100×1024×1024字节，逐个二进制直传，不作base64转换。后端按实际流读取字节数限100MB，支持原JSON/base64兼容请求（135MB请求体），保留登录和来源校验，上传/解析并发限制为1以减少大文件内存压力。DXF解析跳过无关实体和扩展数据。

nginx仅调整固美格CAD接口为135m，兼容100MB原始文件与旧编码请求；不调整其他接口。配置备份在/opt/gugemei/nginx-backups-v1691。

验证：32项测试通过（含恰好100MB的构造DXF完整解析、30文件接受、31文件及100MB+1字节拒绝、二进制接口、源文件计价回归）；生产构建通过。服务器HTTP与HTTPS均发送104857600字节测试请求，得到应用401 JSON，证实完整100MB请求可通过nginx且未绕过认证。未写入用户业务数据。全库TypeScript检查仍为先前记录的既存错误，本次改动没有新增类型错误。
