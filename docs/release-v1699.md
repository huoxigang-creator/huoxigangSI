# V-1-6-99 首页加载、安全问题与识别入口

首页按需加载报价、合同、配置、采购、AI等功能，老板及员工首页不再静态导入报价功能代码。功能加载过程显示状态，失败时可刷新重试。首页主程序从1619327字节降至约112KB，构建依赖测试确认首屏静态依赖不含报价、合同、配置与AI功能包。仅主站的公开哈希静态文件开启Nginx gzip及一年immutable缓存，API及私人数据没有新增缓存。恢复部署需同时上传configure-static-v1699.py，发布脚本调用该脚本；配置修改前备份，语法失败自动恢复。

安全问题设置：错误及成功状态放在保存按钮旁，加载期间禁填防止读取结果覆盖输入，保存成功显示返回的问题与已设置状态；已保存答案仍仅保存摘要、不回显原文。按用户补充，答案下限改为2字符，保存和短信登录/重置验证同步修改，支持两个汉字；安全问题本身仍至少4字符。两次答案按服务器的NFKC、首尾空格、大小写归一化规则比较。原密码校验、旧会话失效、错误次数限制和管理员重设机制保留。

报价识别只保留一个AI智能识别报价按钮，直接进入弹窗，内部截图上传、截图接收和CAD上传保持可用。

验证：12项安全问题服务/HTTP、个人设置、截图接收入口及构建依赖检查通过，TypeScript与生产构建通过。两字中文答案用内存数据库重开服务后验证登录和找回密码；UI模拟保存、错误提示及重新打开。未改真实用户账号和业务数据。额外运行既有月度订单UI测试5项，其中2项原有断言失败；本批未更改月度组件或计算逻辑，未将其计入通过数。浏览器实机交互未验证。
