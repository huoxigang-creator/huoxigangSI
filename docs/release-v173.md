# V-1-7-3 截图状态提示与PDF核对限制

智能识别报价弹窗移除本地OCR备用按钮及该弹窗的本地OCR调用，错误提示改为AI重试或手动补充；其他独立文档功能不改动。

截图粘贴进入后，在文件指纹计算前立即显示已检测到截图、正在读取图片。自动接收返回焦点时显示检查新截图，随后显示准备上传、上传并解析及完成/失败状态。状态栏位于页面上方并保持滚动可见，排队截图明确提示已接收、无需重复截图。图片客户端在读取和压缩前、发起请求前分别报告阶段，不显示虚构百分比；上传与AI解析合并提示，不能单独测得服务器开始解析的时刻。重新识别也更新状态，取消时阻止迟到结果回写。

PDF必须先点击请核对，变为已核对后才启用。按钮禁用和函数检查同时限制未核对生成。修改字段、勾选项、图片或核对状态后取消旧PDF任务结果，撤销下载对象及链接，重新核对才可再次导出。原PDF版式、各柜体信息与最后合计保留。
