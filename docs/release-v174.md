# V-1-7-4 地址用于PDF与数量排版

截图AI和CAD从明确的安装地址/项目地址标注提取address，作为识别行隐藏元数据保留，不新增电脑端地址展示字段，不将地址混入房间、柜名或配置说明。原始截图保留原样。CAD按已放置图框附近的地址标注匹配，预览过滤这些元数据文字；AI多柜体支持同图地址继承，比较两次识别时同时核对地址。不从文件名推测地址。

PDF每个柜体页面的表头使用该条地址加柜体图纸尺寸核对单，无地址的页面保持原表头。选中结果只有一个已知地址时文件名加该地址；多个不同地址时文件名用多地址前缀，各页仍保留各自地址，避免套用首条地址。文件名过滤Windows禁用符号，长表头自动缩小/换行并调整内容位置。自动下载和手动下载链接使用同名。

PDF当前数量和平方米/延米从12pt调至18pt。空单价不显示整行；已填写单价仍显示，数量和单价分行。总平方及延米保留在最后一页底部。

重复行保留原来的图形及首条信息；当先上传裁剪图、后上传含地址的相同柜体时，补充隐藏地址且不修改原对象。不同明确地址的柜体不互相去重，防止跨地址误合并。

验证：54项CAD、截图AI、识别界面、隐藏元数据、去重、PDF内容/字号/空单价/长地址及首页构建测试通过。TypeScript及生产构建通过。对用户提供的DWG在本地实际提取地址，生成一页PDF并渲染检查表头、图形、18pt数量及底部合计；样例和原图未提交GitHub。截图云模型使用模拟接口验证字段提取与传递，未调用付费模型实测准确率。

固美格及锦木均发布V-1-7-4，各自备份和独立品牌/数据保留。线上主站登录200、未登录CAD401；锦木品牌正确、版本174、7个脚本200及gzip正常。沿用V173工作流和configure-jinmu-v172.py的幂等配置，不修改真实业务数据。已打开的旧页面需刷新并重新识别后才能获取新增地址字段。
