# V-1-7-11 CAD预览黑底风格

用户询问截图黑底和CAD白底能否统一，以及哪种更快。选择黑底：CAD生成的SVG改为黑色背景、浅色线条与普通文字、红色柜名及尺寸，尺寸文字描边改为黑色，避免旧白色描边在黑底上影响清晰度。识别结果卡片图形区域底色也改为黑色。截图保留原始像素，因此用户自行上传的白底截图仍保持白底，不进行额外重绘或反色。CAD预览在网页和PDF共用SVG，因此新识别CAD导出也使用黑底。

底色不改变识别方式或模型调用，不能声称带来明显提速；CAD读取结构化标注和截图AI识别仍是不同流程。显示风格统一不代表两种识别耗时相同。

验证：31项CAD及识别界面测试通过，SVG断言黑底、浅色线条、红色尺寸和黑描边，尺寸配对、计价及预览安全规则保持；首页依赖检查、TypeScript及生产构建通过。未修改真实业务数据，未进行真实浏览器手工验收。需刷新并重新上传CAD获取新预览，已识别的旧白底图不会自动重绘。
