# V-1-6-98 项目名称图框识别

截图和CAD采用同一业务规则：这类图纸项目名称后填写的文字作为房间，红色柜体名称作为柜名，只提取对应尺寸。电话、地址、合同、日期、视图标题、材质五金说明等过滤，不写入配置。

CAD支持单独或同行的项目名称字段、索引红色、真彩色及图层/图块继承的红色柜名，按放置后坐标匹配房间。柜体预览保留柜体线条与对应尺寸，过滤其他文字。原房间/柜名格式和计价方式保留。截图AI提示词明确此规则优先于配置提取；本地OCR备用按项目字段取房间，无法确定文字颜色时提示人工核对，多个柜名时不猜测。

验证：43项CAD、上传、截图识别请求和尺寸相关测试通过；TypeScript及生产构建通过。用户提供DWG转换后实际识别一个柜体，房间和柜名正确，尺寸1576×2340毫米，面积3.69平方米，并渲染检查预览。截图AI使用模拟接口验证指令与请求，未调用付费云模型实测，不保证模型每次识别完全正确。未写真实业务记录，未提交用户图纸及测试图像。
