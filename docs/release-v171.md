# V-1-7-1 一张图识别多个柜体

截图上传和剪贴板接收请求多柜体模式，AI先按柜名与相邻图形分组，再分别配对房间及对应外宽外高，最多50条。一个图框共享项目名称后的房间值，多图框按各自房间匹配。带序号红色柜名去除编号；CAD解析也支持此编号形式。

多柜体结果展开为多张核对卡片，共用该文件原图，每条单独编辑、勾选、计价及导出；不自动裁切原图。完全相同房间、柜名、宽高仍过滤。整图重新识别替换该文件的原明细，整批重新识别先按文件引用去重，避免为同一文件的多个柜体重复调用。保留原模型重试逻辑。

仍进行两次识别对比，返回顺序变化不算不一致；柜体数量或尺寸不一致时取消勾选并提醒核对原图是否漏项。旧单柜体接口及文字识别保持兼容，本地OCR备用仍无法可靠分柜，复杂图建议CAD或分图核对。尺寸计价按原规则执行，预览和PDF均对应每条柜体明细。

验证：48项截图多柜体服务/HTTP、界面、CAD、计价和PDF测试通过，TypeScript及生产构建通过。模拟同图两柜1313×940及1312×900合计2.41平方米，重新识别后保持两条；未调用付费云模型实测该截图，准确率仍需用户对照原图核对。无真实业务数据写入。发布继续保留旧静态资源，避免已打开页面PDF导出404。
